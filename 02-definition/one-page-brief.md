| | |
|---|---|
| **Product** | MediLens, AI pharma intelligence and outreach |
| **Problem** | Finding and reaching decision-makers at healthcare businesses is slow, manual and inconsistent. |
| **Users** | Territory sales reps, medical science liaisons, small distributors *(hypothesis)* |
| **Solution** | Discover on a map, enrich contacts, score reachability, generate and send personalised outreach. |
| **Goals** | Search-to-draft in minutes. Rank accounts by how reachable they are. Messages that read as written for the recipient. |
| **Non-goals (v1)** | Full CRM. Team collaboration. Clinical decision support. Bulk spam. Contact data resale. |
| **Key metrics (proposed)** | Time from search to first draft. Share of accounts with a reachable contact. Reply rate on sent messages. |
| **Status** | Built and deployed; one internal test run; no users. |
| **Biggest risks** | Data-protection compliance. No per-user data ownership or rate limits yet. Data accuracy. Email deliverability. (Open endpoints and an open database were fixed on 23 Nov 2026.) |
| **Next step** | Finish phase 0 (rate limits, ownership, one score formula), then 5 to 8 user interviews and a supervised pilot with real territory searches. |
